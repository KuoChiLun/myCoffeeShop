# ☕ Pour Over Coffee Timer (手沖咖啡計時器)

一個專為手沖咖啡愛好者設計的專業計時工具。介面簡潔、聚焦，並針對行動裝置進行優化，讓您能專注於每一次的萃取。

👉 **[立即使用 (Demo)](https://KuoChiLun.github.io/myCoffeeShop/)**

---

## ✨ 核心特色

- ⏱ **聚焦計時介面**：超大字體顯示，計時中僅顯示「當前」與「下一步」，資訊清晰不干擾。
- ⚖️ **即時粉水比**：隨注水量即時計算萃取比例（如 1:15.0），精準掌握口感。
- 📋 **靈活食譜設定**：內建 V60、Kalita 等經典預設，並支援自定義沖煮階段與備註。
- 📱 **PWA 行動應用化**：
  - **離線支援**：即使在無網路環境也能正常運作。
  - **加入主畫面**：可像原生 App 一樣安裝在手機桌面，全螢幕無網址列。
- 📓 **沖煮筆記**：完整記錄豆子資訊、水溫、研磨度及風味評分。

---

## 🛠 技術棧

- **HTML5 / CSS3**：響應式設計，完美適應各類手機螢幕。
- **JavaScript (Vanilla JS)**：純原生開發，輕量且極速。
- **Service Workers**：實現離線快取與 PWA 體驗。
- **GitHub Pages**：自動化部署與全球 CDN 加速。

---

## 🚀 如何使用與部署

### 本地開發
1. 複製此倉庫：
   ```bash
   git clone https://github.com/KuoChiLun/myCoffeeShop.git
   ```
2. 直接在瀏覽器開啟 `index.html`，或使用簡易伺服器：
   ```bash
   python -m http.server 8000
   ```

### 部署到自己的 GitHub
1. 將專案推送到您的 GitHub 倉庫。
2. 前往 **Settings > Pages**。
3. 將 **Branch** 設定為 `main` 分支並儲存。
